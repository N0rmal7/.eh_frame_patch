# IDA 9.0 集成说明

1.0.1 编辑器使用 IDA 9.0 的 PyQt5 QDialog，不再使用多行原生 Form 和 ChkGroupControl。原版在本次真实渲染中出现 768×1406 的异常布局，复选框状态未可靠进入计划。

新版提供同窗输入和预览，180 ms 合并输入事件，在 Patch 时同步重算；地址、预算解析失败时禁止写入。预览限制前 512 字节，完整补丁仍按预算检查和保存。

代码转换先检查既有数据项边界及全部指令长度，不对整个段修改属性。不能完整转换时保留已写入字节并明确说明。

测试通过脚本驱动独立 IDA 进程；未替换机器上安装的 1.0.0。脚本在导入评测副本前清除旧 ehp 模块缓存，避免测试误用已安装核心。用户更新必须替换入口和 ehp 目录并重启。
